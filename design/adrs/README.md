# Architecture Decision Records (ADRs)

Significant decisions are recorded as ADRs. They are currently summarised inline in
`design/D3-technical-architecture.md` Section 14 (ADR-001 to ADR-014). As the codebase grows,
split each into its own file here using the convention `NNNN-title.md`, for example
`0001-open-source-first-stack.md`.

Suggested ADR template:

```
# ADR-NNNN: <title>
Status: proposed | accepted | superseded by ADR-XXXX
Date: YYYY-MM-DD

## Context
## Decision
## Alternatives considered
## Consequences
```
